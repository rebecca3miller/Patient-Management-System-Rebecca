## Patient Management System

## Project Overview

For this project, I created a Patient Management System using Java. The program uses a 
queue to manage patients in a waiting room and a doubly linked list to store patient history records.
The waiting room allows patients to be added, served in order, and inserted at a specific position 
in case of an emergency. The patient history system allows users to view the oldest and newest records 
and move forward or backward through the history. I also created a menu using Scanner so users can 
interact with the program and added JUnit tests to check that the main features work correctly.
